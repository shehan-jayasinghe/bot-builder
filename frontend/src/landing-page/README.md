# AgentForge Landing Page

Public marketing landing page for the Bot Builder platform.

## Structure
- `LandingPage.tsx` — complete page composition and content
- `landing-page.css` — isolated responsive landing-page styles
- `assets/agentforge-logo.svg` — AgentForge wordmark
- `assets/agentforge-icon.svg` — application/brand icon
- `assets/agent-hero.svg` — custom AI agent hero illustration

## Sections
Hero, platform overview, workflow/value flow, features, industry use cases, four-step onboarding, observability metrics, CTA and footer.

The public route is `/`. The authenticated dashboard home remains available at `/app`; existing agent/workflow/application routes are unchanged.
